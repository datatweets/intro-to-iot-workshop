# Labs

Six hands-on labs and one group activity. Each lab builds on the one before,
so do them in order. Before Lab 1, set up your accounts with
[Getting started](../1-getting-started/).

| | Lab | What you'll do | Module | Time |
|---|---|---|---|---|
| 1 | [Digital vs Analog](lab-1-digital-vs-analog/) | Blink a light, read a button and turn a dial | 3 | 25 min |
| 2 | [Temperature and Humidity](lab-2-temperature-and-humidity/) | Read a real sensor, the DHT22 | 3 | 25 min |
| 3 | [Wi-Fi and MQTT](lab-3-wifi-and-mqtt/) | Get online and send live readings across the internet | 4 | 30 min |
| 4 | [Cloud Dashboard](lab-4-cloud-dashboard/) | Send readings to ThingSpeak and watch a live chart | 5 | 30 min |
| 5 | [Automation](lab-5-automation/) | Make a fan and alarm switch on by themselves when it's too hot | 6 | 30 min |
| — | [Spot the Vulnerability](activity-spot-the-vulnerability/) | Group activity: find the security mistakes (no coding) | 7 | 20 min |
| 6 | [Smart Environment Station](lab-6-smart-environment-station/) | Put it all together in one complete project | 8 | 45 min |

## What's in each lab folder

- **The PDF guide**, with a picture for every step. Start here.
- **`sketch.ino`**: the code that runs on the ESP32.
- **`diagram.json`**: the circuit, ready-wired.
- **`libraries.txt`** (Labs 2 to 6): the list of extra code packages Wokwi
  needs to install.

To copy a code file, click it, then click the **Copy raw file** button (two
overlapping squares, at the top right of the code).
